Quick Start

AuraDB is a cloud-native graph database optimized for AI workloads. The Python SDK provides synchronous and asynchronous interfaces for querying, schema management, and real-time subscriptions.

from auradb import Client, QueryBuilder

# Initialize client
db = Client(
    endpoint="https://your-cluster.aura.example.com",
    api_key="sk-aura-xxxxxxxxxxxx"
)

# Simple query
results = db.query("""
    MATCH (n:User {active: true})
    RETURN n.name, n.email
    LIMIT 10
""")

for row in results:
    print(row.name, row.email)

Graph Schema Management

AuraDB uses a schema-first approach. Define your node and edge types using the schema API or the AuraDB Schema Language (ASL), a superset of the Cypher schema notation.

from auradb.schema import NodeType, EdgeType, Field

# Define schema
user_type = NodeType(
    name="User",
    fields=[
        Field("id", type="uuid", primary=True),
        Field("name", type="string", indexed=True),
        Field("email", type="string", unique=True),
        Field("created_at", type="datetime"),
    ]
)

follows_type = EdgeType(
    name="FOLLOWS",
    source=user_type,
    target=user_type,
    fields=[Field("since", type="datetime")]
)

db.schema.apply([user_type, follows_type])

Async Support

The AuraDB SDK provides full async/await support for high-throughput applications:

import asyncio
from auradb import AsyncClient

async def main():
    async with AsyncClient(
        endpoint="https://your-cluster.aura.example.com",
        api_key="sk-aura-xxxxxxxxxxxx"
    ) as db:
        # Concurrent queries
        results = await asyncio.gather(
            db.query("MATCH (n:User) RETURN count(n)"),
            db.query("MATCH ()-[e:FOLLOWS]->() RETURN count(e)")
        )
        print("Users:", results[0][0].count_n)
        print("Follows:", results[1][0].count_e)

asyncio.run(main())

Error Handling

AuraDB provides structured error types for common failure modes:

from auradb.errors import (
    AuthenticationError,
    SchemaConflictError,
    QueryTimeoutError,
    RateLimitError
)

try:
    results = db.query("MATCH (n:User) RETURN n", timeout=30)
except QueryTimeoutError:
    print("Query exceeded timeout")
except AuthenticationError:
    print("API key invalid or expired")
except RateLimitError as e:
    print(f"Rate limited. Retry after {e.retry_after}s")

Performance Tuning

For high-throughput workloads, configure connection pooling and batch operations: use Client(pool_size=20) for concurrent query workloads, use db.batch_write() for bulk mutations (up to 10x faster than individual writes), enable query_cache=True for read-heavy workloads with stable data, and profile slow queries with db.explain(query) to view the execution plan.
