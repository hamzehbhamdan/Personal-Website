Understanding MCP Sampling

MCP sampling allows servers to request AI completions through the client, enabling sophisticated agentic behaviors. However, this creates a reverse prompt flow where the server can influence the client's AI model through carefully crafted sampling requests.

Security Implications

  • Sampling requests can contain injected system prompts that override client instructions
  • The includeContext parameter can cause sensitive context to be shared with the server
  • Conversation history in sampling requests can contain embedded injection payloads
  • Without origin authentication, sampling requests cannot be verified as legitimate
